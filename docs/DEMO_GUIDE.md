# 🎤 Demo Guide — ลำดับการสาธิตสำหรับนำเสนอ

ใช้เวลาประมาณ 8–10 นาที เปิด `index.html` (หรือ [Live Demo](https://nexus-space-six.vercel.app)) ก่อนเริ่ม
ในโหมด Local Preview ข้อมูลจะกลับเป็น Seed Data ทุกครั้งที่รีเฟรช จึงซ้อมซ้ำได้

---

## 1. ภาพรวมฐานข้อมูล (เมนู “ฐานข้อมูล”) — 2 นาที

1. ชี้แผนภาพ ERD: `MEMBER → BOOKING → BOOKING_ROOM ← ROOM` และ `BOOKING → BOOKING_EQUIPMENT ← EQUIPMENT`
2. เล่าการปรับตามคำแนะนำอาจารย์
   - ยุบ `PAYMENT` เข้า `BOOKING` (ฟิลด์ `PAYMENT_METHOD / PAYMENT_STATUS / PAYMENT_DATE`)
   - เพิ่ม `BOOKING_ROOM` ให้ 1 ใบจองมีหลายห้อง (Composite PK)
3. เลื่อนดู Data Dictionary ทุกคอลัมน์ + ตาราง Foreign Key (RESTRICT / CASCADE) + จำนวนแถวของแต่ละตาราง

## 2. ตารางการใช้ห้อง (เมนู “จองห้อง”) — 2 นาที

1. กด **“ดูวันที่มีข้อมูลตัวอย่าง”** → ไปวันที่ 21 ก.ย. 2569 เห็นบล็อก BK20260901–03
2. ชี้ว่า BK20260902 อยู่ทั้งแถว **Focus Pod A** และ **Focus Pod B** = จองหลายห้องผ่าน `BOOKING_ROOM`
3. คลิกบล็อกใดก็ได้ → เปิดใบยืนยันการจอง (JOIN MEMBER + ROOM + EQUIPMENT)
4. คลิกช่องว่างของ Focus Pod A เวลา 11:00 → กรอบแดง **“ชนกับการจองเดิม”** + ปุ่มยืนยันถูกปิด (และวันที่ย้อนหลังจองไม่ได้)

## 3. จองหลายห้อง + อุปกรณ์ — 3 นาที

1. กด **“วันนี้”** แล้ว **›** ไปวันพรุ่งนี้
2. คลิกช่อง **Focus Pod A 13:00** แล้วกด “เลือกห้อง” ที่ **Brainstorm Studio** → เลือก 2 ห้อง
3. ตั้งเวลา 13:00–15:00 → เพิ่ม **ไมโครโฟน × 2**
4. ราคาที่ควรเห็น: `2 ชม. × (120 + 250) + 120 × 2 = ฿980.00`
5. กรอกสมาชิกใหม่ (ชื่อ/นามสกุล/เบอร์ 10 หลัก/อีเมลใหม่) เลือก **Cash** → สถานะหลังยืนยัน = `Pending`
6. กดยืนยัน → ได้ใบยืนยันเลขที่ `BK<วันนี้>01` ตรา **PENDING** และสมาชิกใหม่ `M005`
7. ลองจองห้องเดิมช่วงเวลาเดิมอีกครั้ง → ระบบไม่ให้จอง

## 4. ค้นหาประวัติ (เมนู “การจองของฉัน”) — 1 นาที

- กดตัวอย่าง `0812345678` → ประวัติของ M001
- กด `BK20260903` → ค้นด้วยเลขที่ใบจองโดยตรง

## 5. ผู้ดูแลระบบ — 1 นาที

1. ชี้ KPI: รายรับที่ชำระแล้ว, รอชำระ, บิลหลายห้อง
2. เปลี่ยน `PAYMENT_STATUS` ของใบจองที่สร้างในข้อ 3 จาก `Pending` → `Paid` → KPI อัปเดตทันที
3. เปลี่ยน `STATUS` เป็น `Cancelled` → ช่วงเวลาในตารางว่างทันที (ใบจองที่ยกเลิกไม่นับการชน)
